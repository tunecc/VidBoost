# 目标

为 Bilibili 画质功能（`bb_quality`）增加“屏蔽画质”能力：用户可把某档画质（如 1080P 高码率）标记为屏蔽；画质功能在自动选择画质时绝不选中被屏蔽档位：

- 期望画质（目标画质 / 默认画质）可用且未被屏蔽时照常使用（例：目标 1080P60 且视频提供 1080P60 时播 1080P60）；
- 期望画质不可用或本身被屏蔽时，回退选择跳过被屏蔽档位（例：视频只有 1080P 高码率和 1080P 时，播 1080P 而不是高码率）。

# 范围

- `src/lib/bilibiliQuality.ts`：画质候选过滤逻辑（新增屏蔽过滤辅助函数，被屏蔽档位从候选中剔除）。
- `src/features/BilibiliAutoQuality.ts`：选择链（期望 → 回退 → 最佳可用）应用屏蔽过滤。
- `src/lib/settings.ts`：`BilibiliQualityConfig` 增加 `blockedQns` 字段、默认值与 `resolveSettings` 归一化。
- `src/lib/__tests__/bilibiliQuality.test.ts`：新增选择链与屏蔽过滤的单元测试。
- `src/popup/App.svelte`：画质设置区新增「屏蔽画质」多选控件（保存 / 载入 / 回显）。
- `src/lib/i18n.ts`：en / zh-CN 两侧新增文案。

# 非目标

- 不覆盖 YouTube / 抖音（扩展目前仅 B 站有画质功能）。
- 不在视频播放中途强制切走用户手动切换到的被屏蔽画质：功能仅在页面加载 / SPA 导航时应用，与现状一致。
- 不新增设置同步消息通道（沿用 `storage.onChanged` 链路）。
- 不改变 UP 主名单 / 双档画质（目标 / 默认）现有模型。

# 验收示例

- `A1` 回归基线：`blockedQns` 为空（默认，含存量用户设置）时，画质选择链结果与未引入屏蔽列表前完全一致。
- `A2` 屏蔽 1080P 高码率（112），目标画质=1080P60（116），视频菜单可用 [116, 112, 80] → 点击 116（1080P60）。
- `A3` 屏蔽 112，目标画质=116，菜单可用 [112, 80] → 点击 80（1080P），全程不得点击 112。
- `A4` 屏蔽 112：目标画质=112（矛盾配置）时落点为 80；目标画质=80、可用 [112, 80] 时仍为 80。
- `A5` 多选同时屏蔽 112 与 126（杜比），目标画质=125（HDR），可用 [126, 112, 80] → 落点 80，两个被屏蔽档都不被选中。
- `A6` 全部可用档均被屏蔽（如屏蔽 {80, 112} 且可用 [112, 80]）→ 忽略屏蔽按原选择链落点（112），不放弃管理画质、不残留 B 站默认行为。
- `A7` 屏蔽列表为 popup 多选控件：勾选保存后，已打开的视频页通过 `storage.onChanged` 即时重新应用（无需重载扩展或刷新页面）；重新打开 popup 回显与保存一致；en / zh-CN 文案齐全。
- `A8` 回退次序不因屏蔽改变：期望档不可用时选不高于期望档的最近可用档，全部可用档高于期望档时选最佳可用档（与现有 `pickBilibiliQualityAtOrBelow` 语义一致）。
- `A9` 单元测试 `npx vitest run src/lib/__tests__/bilibiliQuality.test.ts --environment=jsdom` 覆盖 A2–A6、A8 的纯逻辑且全部通过；`npm run check` 通过；`npm run build:chrome` 成功。

# 约束与不变量

- 屏蔽列表为空（默认）时所有现有行为不变。
- 屏蔽过滤不得让画质功能放弃管理：若过滤后无任何可用候选，则忽略屏蔽列表按原逻辑选择（宁选被屏蔽档也不放任 B 站默认）。
- `bilibili_player_settings` localStorage 快照 / 恢复机制保持不变。
- 屏蔽列表在各站点账号权限不同的情况下不改变“VIP 档位可见性”处理方式。

# 决策

- 屏蔽列表作用于整条画质选择链（期望档、回退档、最佳可用档）——语义为“被屏蔽档位绝不自动选中”。
- 屏蔽与目标 / 默认画质两个下拉相互独立：不阻止用户把被屏蔽档设为期望档，由选择逻辑在运行时过滤。
- （Q1，用户未作答，按推荐方案决定）popup 中“屏蔽画质”控件采用**多选屏蔽列表**：全部画质档位以勾选项呈现，可同时屏蔽多档；不勾选任何档位即为不屏蔽。“屏蔽某一种”是该形态的特例，功能为超集，避免后续改动 UI。
