# 目标

重做 YouTube 视频控件栏字幕选择面板：让「自动翻译」分组里的简体中文、繁体中文固定排在最前，其余语言按名称首字母排序；同时把面板顶部常驻的搜索输入行改成右上角搜索按钮（点击才展开），并按 YouTube 原生菜单风格整体重设计面板视觉。

# 范围

- `src/features/youtube/subtitle/selector/catalog.ts`：自动翻译分组的排序规则（中文简繁置顶）。
- `src/features/youtube/subtitle/selector/SubtitleSelector.ts`：面板结构（标题行 + 右上角搜索按钮 + 可展开搜索行 + 列表）与整体样式。
- `src/lib/i18n.ts`：为搜索按钮新增所需文案（en / zh 两套）。
- `src/features/youtube/subtitle/selector/__tests__/`：排序与面板交互的单元测试。

# 非目标

- 不改「视频提供」分组的排序规则（仍是标签升序）。
- 不加分组折叠、不加面板内关闭按钮、不加语言代码副行。
- 不改字幕请求、下载、后处理与渲染逻辑（属 `subtitle-rendering` 能力）。
- 不改 popup 设置界面的字幕设置。
- 不做亮色主题/多主题适配，不引入新运行时依赖，不改 manifest 与权限。

# 验收示例

- `A1` 当翻译语言同时含简中与繁中时，面板「自动翻译」分组前两项依次为简体中文、繁体中文，第三项起为其余语言按标签升序。
- `A2` 置顶只按语言代码判定（`zh-Hans`/`zh-CN`/`zh-SG`/`zh-MY` 为简体，`zh-Hant`/`zh-TW`/`zh-HK`/`zh-MO` 为繁体）；YouTube 界面为英文、标签是 "Chinese (Simplified)"/"Chinese (Traditional)" 时同样置顶。
- `A3` 简体中文因与视频自带字幕语言兼容而被去重跳过时，繁体中文成为「自动翻译」第一项，其余顺序不变，列表中不出现重复或缺位。
- `A4` 翻译语言中没有中文时，「自动翻译」顺序等于纯标签升序（与改动前一致）；「视频提供」分组顺序不受影响。
- `A5` 中文标签按拼音序、拉丁标签按字母序排列（排序结果确定且可被单元测试复现）。
- `A6` 面板打开后顶部是一行标题：左侧显示面板标题文案，右侧显示搜索图标按钮，此时不显示搜索输入行。
- `A7` 点击搜索按钮后标题行下方展开搜索输入行，输入框自动获得焦点，按钮显示激活态；输入关键词后两组语言项按现有规则实时过滤。
- `A8` 再次点击搜索按钮收起搜索行，同时清空搜索词并恢复完整列表（不出现「列表被过滤却看不到搜索框」的状态）。
- `A9` 搜索行展开时按 Esc 只收起并清空搜索行、面板保持打开、焦点回到搜索按钮；再按一次 Esc 才关闭面板。
- `A10` 搜索行展开时通过点击面板外部或再点控件栏按钮关闭面板后，重新打开面板搜索行为收起且无残留搜索词。
- `A11` 面板样式贴合 YouTube 原生深色菜单：去掉现有 1px 外边框与强阴影，实色深底、更大圆角，列表项 hover 出现浅色背景、选中项为淡蓝背景 + 勾选标记。
- `A12` 语言项徽章改为弱化小字（不再是实色胶囊底），仍能区分并显示「作者 / 自动生成 / 翻译 / 默认」信息；分组标题保持小字弱化样式。
- `A13` 窄播放器（面板宽度取 `min(360px, 100% - 24px)`）与短播放器下，面板不超出播放器可视区域，窗口改变尺寸后重新定位仍完整可见；长语言标签换行且不与徽章重叠。
- `A14` ↑/↓ 键盘导航在搜索展开与收起两种状态下都只遍历当前可见项，且新样式下焦点环仍然清晰可见。
- `A15` 无功能回归：点击语言项仍以目标语言代码回调并关闭面板；控件栏按钮图标激活/未激活两态与挂载位置不变；无可显示语言项时按钮与面板不挂载；`npx vitest run src/features/youtube/subtitle/selector --environment=jsdom` 全部通过（含改动前已有的 35 项）且 `npm run check` 通过。
- `A16` 搜索按钮有可访问名称与展开状态（`aria-label` + `aria-expanded`），中文界面显示「搜索语言」、英文界面显示 "Search languages"，新增文案 key 在 en 与 zh 两套字典中都存在。

# 约束与不变量

- 面板继续是 content script 内的纯 DOM + 行内样式实现，不引入 Svelte 或 CSS 文件。
- 排序只在 `catalog.ts` 构建菜单时完成一次；渲染层与键盘导航层不得各自再排序，保证显示顺序与导航顺序一致。
- 选项 `id`、`targetLanguageCode`、`searchText` 字段语义与 `onSelectLanguage(targetLanguageCode)` 契约不变。
- 中文简繁识别复用 `language.ts` 已有的 script/region 分组语义（`HANS_REGIONS`、`HANT_REGIONS`），不新增硬编码语言码清单的第二份真相。
- 置顶项之间以及置顶项与普通项之间仍走同一套去重结果，不因置顶逻辑绕过 `areTargetLanguagesCompatible` 去重。
- 搜索行的展开/收起状态是面板内局部状态：`open()`、`close()`、`detach()` 后一律回到「收起 + 空查询」。
- Chrome 与 Firefox 共用同一份代码，不新增 `*.firefox.ts` 分支。

# 决策

- 美化范围 = 整体重新设计（用户在 Shape 中选择，非仅搜索行改造）。
- 视觉基准 = 贴合 YouTube 原生菜单风格（用户决定）。
- 分组不折叠，保持平铺（用户决定）。
- 语言项 = 语言名 + 弱化徽章，不加语言代码副行；选中项用淡背景 + 对号（用户决定）。
- 右上角只放搜索按钮，不加关闭按钮（用户决定）。
- 搜索按钮不画焦点白圈：固定 `outline:none` 且 focus/blur 不改写 outline，只用蓝色底 + 蓝色图标表示搜索生效（用户真机查看后决定，属实现修订，不改 A1–A16 验收文字）。
- 收起搜索行时清空搜索词并恢复完整列表（用户决定）。
- Esc 分层退出：先收起搜索行，再关闭面板（用户决定）。
- 简繁置顶仅作用于「自动翻译」分组，顺序为简体在前、繁体第二（用户原话的列举顺序）。
- 置顶按语言代码判定而非标签文本，使英文 YouTube 界面下行为一致（实现决定，影响 A2）。
- 排序用固定 locale 的 Collator（中文标签取拼音序），避免依赖宿主浏览器 UI 语言导致结果不稳定（实现决定，影响 A5）。

# 验证预期

- 单元测试：`catalog` 排序（简繁置顶、去重交互、英文标签、无中文回退到纯升序）与 `SubtitleSelector` DOM 行为（标题行 + 搜索按钮展开/收起、Esc 分层、查询清空、aria 状态、键盘导航）。测试命令：`npx vitest run src/features/youtube/subtitle/selector --environment=jsdom`（基线 35 项通过，改后不得减少）。
- 静态检查：`npm run check`（svelte-check）。
- 打包冒烟：`npm run build:chrome` 成功产出 `dist/`；因未改 manifest/权限，不要求跑 Firefox 低内存验证。
- 人工核对：真实 YouTube 视频（有作者字幕 + 可翻译轨道）打开面板，核对 A1、A6–A14 的观感与交互；Verifier 对纯样式项（A11–A13）以代码阅读方式判断。
